# Makassar City Information Website

A responsive informational website that introduces the history, tourism,
and culinary highlights of Makassar City.

## 📌 About the Project

This project was developed as a Front-End Web Development project during
my learning journey at Dicoding in 2026.

The website presents information about Makassar City through a simple,
structured, and user-friendly interface.

## 🎯 Project Purpose

The purpose of this project is to create an informative website that
introduces Makassar through three main topics:

- History of Makassar
- Tourism, especially Pantai Losari
- Traditional culinary, especially Coto Makassar

## ✨ Features

- Responsive website layout
- Navigation between website sections
- Historical information about Makassar
- Tourism information
- Culinary information
- Author profile section
- Back-to-top button
- Interactive JavaScript functionality

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
